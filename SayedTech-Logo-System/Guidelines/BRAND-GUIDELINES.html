03
Typography
الخطوط

Mawzoon is reserved for branding only — the logo and wordmark. Every other piece of text uses the body system below. This keeps the brand mark distinctive and the running text legible.

04
Clear Space & Minimum Size
المساحة الآمنة

Clear space ≥ the height of the icon mark on all sides.

↔ clear space = icon height

Minimum — Horizontal: 120px wide. Icon: 24px. Favicon tested legible to 16px.

05
Usage Rules
قواعد الاستخدام

Do

  • Use approved SVG/PNG files only
  • Keep monochrome as default
  • Preserve سيد(fill) / التقنية(outline)
  • Keep both words equal width
  • Use Mawzoon for the logo/wordmark only
  • Use Tajawal for all other Arabic text
  • Use accent teal sparingly

Don't

  • Set body or caption text in Mawzoon
  • Recolor or outline-swap the wordmark
  • Stretch, skew, or rotate
  • Round the badge corners
  • Add shadows, bevels, gradients to the mark
  • Place on busy backgrounds
